# LA Referencia Entity REST API

RESTful API for accessing and searching scholarly entities from Elasticsearch.

## 🎯 Functionality

Provides endpoints for entity search, retrieval, relationship navigation, and semantic identifier resolution. Supports Publications, Persons, Organizations, and Projects with full-text search, faceting, and pagination.
